# table-manners

The shared contract of the waffle tools: one external interface for
[squint](https://github.com/markhayden/squint) (checks an image against what was asked of it),
[rascal](https://github.com/markhayden/rascal) (finds, masks and composites regions) and the tools
after them. Each tool keeps its own intent and internals; what an agent or a pipeline sees from
outside is the same in all of them, so they chain without glue code.

A **core** covers every tool: results, self-description, long runs, the MCP server, exit codes.
**Profiles** add what a kind of tool needs: **images**, which squint and rascal implement, and,
from v0.4, **operations**, which rascal implements.

- [`CONTRACT.md`](CONTRACT.md): the specification: v0.6.0 on branch `v0.6` (per-choice readiness, installables, `install` and `uninstall`), ready to tag; v0.5.0 is the latest tag.
- [`schemas/`](schemas): the JSON Schemas, the source of truth: `core/` for every tool, `images/`
  for the images profile, `operations/` for the operations profile.
- [`examples/`](examples): valid and invalid documents for each schema.
- [`vectors/pixels/`](vectors/pixels): PNG test vectors for the pixel digest, written by
  `make.py` from known samples.
- The `table-manners` crate (this directory): serde types matching the schemas, which it
  embeds. No logic.
- [`MAPPING.md`](MAPPING.md): what squint and rascal change to conform.
- [`fixtures/`](fixtures): each tool's conformance fixtures, generated by the tool and validated
  here against the schemas (`fixtures/rascal/`, `fixtures/squint/`; both at v0.6).
- [`PROPOSALS.md`](PROPOSALS.md): changes proposed for later versions, and C4 as agreed for v0.2.
- `acceptance/` (the cross-tool test) follows with the mask handoff.
